# v3.2 - ORM e integracion continua

Esta version conserva las pruebas unitarias y las Katas TDD de las versiones anteriores. Agrega un mini ORM educativo basado en anotaciones Java y persistencia en tablas CSV locales.

## ORM implementado

- `@Table`: define el nombre de la tabla.
- `@Column`: define el nombre de la columna.
- `@Id`: identifica la clave primaria.
- `CsvOrmRepository<T>`: mapea entidades Java a una tabla local.
- `OrmProductoRepository`: adapta el ORM al repositorio de productos.

## Ejecutar pruebas

```bash
bash scripts/test.sh
```

## Ejecutar sistema con persistencia local

```bash
bash scripts/run.sh
```

Los datos se guardan en la carpeta `data/`.
